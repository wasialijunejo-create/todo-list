# To-Do List

A simple, responsive to-do list built with **HTML, CSS and vanilla JavaScript** (no libraries).

## Features
- Add tasks (press Enter or click **Add**)
- Mark tasks as done or not done
- Delete a task, or clear all completed tasks
- Filter by **All / Active / Completed**
- Live counter of tasks left
- Tasks are saved in the browser (`localStorage`), so they stay after refresh
- Dark theme and mobile friendly

## How to run
No installation needed. Download the files and open `index.html` in your browser.

## What I practiced
- DOM manipulation (`createElement`, `append`, `replaceChildren`)
- Events (form submit, click, change)
- Arrays and objects (`filter`, `find`, `forEach`)
- `localStorage` with `JSON.stringify` / `JSON.parse`
- Safe text output with `textContent`
